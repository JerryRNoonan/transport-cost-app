# transport-cost-app
Is a standardize state-of-the art chart of transport costs for the classification of all types of transactions for a truckload carrier.
The chart of cost accounts breaks down for a truckload carrier five key cost segments: Variable Over-the-Road Production Costs to move a truck
from an origin point to a destination point.  The model creates a transport margin account that measures the dollars, miles, hours, or some 
other common units of measurement.  The model has four remaining overhead cost segments that consists of Fixed Line Haul Costs, Shop Costs, 
Administrative Costs, and a build in profit costs that equals a fair and reasonable rate of return on invested capital.  Model has been used
in numerous cases to improve operating performance for a truckload carrier.
